## 🔧 Python 工具函数

```python
# 区号转城市/省份/区域
DISTRICT_CODE_MAP = {
    '010': ('北京', '北京', '北区'),
    '1101': ('北京', '北京', '北区'),
    '021': ('上海', '上海', '东区'),
    '3101': ('上海', '上海', '东区'),
    '020': ('广州', '广东', '南区'),
    '4401': ('广州', '广东', '南区'),
    '0571': ('杭州', '浙江', '东区'),
    '3301': ('杭州', '浙江', '东区'),
    # ... 完整映射见上方表格
}

def parse_district_code(code):
    """
    解析区号，返回 (城市，省份，区域)
    例：'3301-' → ('杭州', '浙江', '东区')
    """
    if not code:
        return (None, None, None)
    
    # 去掉末尾的 '-'
    code = code.rstrip('-')
    
    # 去掉开头的 '0'（如 '0571' → '571'）
    if code.startswith('0') and len(code) > 3:
        code = code[1:]
    
    # 尝试匹配（从长到短）
    for length in [6, 5, 4, 3]:
        prefix = code[:length]
        if prefix in DISTRICT_CODE_MAP:
            return DISTRICT_CODE_MAP[prefix]
    
    return (None, None, None)

# 使用示例
city, province, region = parse_district_code('3301-')
# 返回：('杭州', '浙江', '东区')
```

## ⚠️ 注意事项

1. **区号格式不统一** - 有 `3301-`、`0571-`、`310115-` 等多种格式
2. **可能为空** - 不是所有客户都填写了区号
3. **新区号** - 部分地区区号调整，需及时更新
4. **国外客户** - 国外区号格式不同（+ 国家码）
