## 🔧 使用方法

### 查询逻辑

当用户问"**XX 省的 XXX 商机/客户**"时：

1. **查省份属于哪个区域**
   - 例：杭州 → 浙江省 → 东区
   - 例：广州 → 广东省 → 南区
   - 例：北京 → 北京市 → 北区

2. **查询对应区域的商机/客户**
   ```python
   # 伪代码
   region = get_region_by_province("浙江省")  # 返回 "东区"
   query_opportunities(filters=[{"field": "1751888184000030", "operator": "EQUALS", "value": region}])
   ```

3. **可选：进一步筛选**
   - 如果需要精确到城市，再用区号过滤
   - 区号字段 ID：`1751888184000011`

## 💡 CRM 字段说明

| 字段名 | 字段 ID | 说明 |
|--------|--------|------|
| 区域 | `1751888184000009` (客户) / `1751888184000030` (商机) | 东区/南区/北区 |
| 区号 | `1751888184000011` | 电话区号，如 `3301-` |
| 行业 | `1751888184000005` | 客户行业分类 |

---

## ⚠️ 注意事项

1. **CRM 系统只有区域字段，没有省份字段** - 必须通过城市→省份→区域的映射来查询
2. **区号可以精确判断城市** - 优先使用区号字段判断具体城市
3. **国外客户也分区域** - 印尼/沙特=南区，俄罗斯/白俄罗斯/哈萨克斯坦=东区
